How to use it

From board to firmware in four steps

You need a PC, a USB data cable and the activation key you received from StepLab.

01

Download and run

Download the .exe file and open it: there is nothing to install. You can copy it to a USB stick and use it on any Windows PC.

02

Enter your key

The first time you start it, enter your activation key (XXXX-XXXX-XXXX-XXXX). The program loads the firmware list.

03

Connect the board

Connect the ESP32 over USB, pick the Porta COM (COM port) and press Rileva chip. Then choose your board from the list.

04

Flash the firmware

Choose the mode and press Carica firmware (flash firmware). When writing is done, the board restarts with the new software.

Requirements

What you need to get started

No development environment, no programming skills: just a PC and a USB cable.

A Windows PC

Windows 10 or 11. The program is a single file: it even runs from a USB stick.

A USB data cable

To connect the ESP32 board to the PC. If the port doesn't show up, install the CP210x or CH340 USB-serial driver.

An activation key

Provided by StepLab: it gives access to your firmware and can be updated or revoked at any time.

FAQ

Need help?

Windows shows a warning when I open the program

SmartScreen may flag less common programs downloaded from the Internet. Click More info, then Run anyway.

I can't see any COM port

Make sure the USB cable carries data, try another USB port on the PC and install the board's USB-serial driver (CP210x or CH340). Then press Aggiorna (refresh) next to the port list.

How do I get an activation key?

StepLab provides the key. If you didn't receive it or have lost it, contact us. If you work for several clients, add each key with Aggiungi… (add) in Opzioni → Licenza (Options → Licence) and pick the client from the list.

Does an update erase the board's settings?

No: a firmware update keeps the device's settings and files. Only a full installation erases the whole flash memory.

Flashing stops or doesn't start

Close other programs using the same COM port (serial monitors, IDEs), then try again with a lower Velocità (speed). On some boards you need to hold the BOOT button while flashing starts.

Do I have to download the program again for new versions?

No: at startup the Flash Tool checks for a newer version and offers Scarica (download) or Salta (skip). The new executable replaces the old one and the program restarts.
