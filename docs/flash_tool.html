ST ESP32 Flash Tool

Come caricare il firmware sulle schede ESP32 con ST_ESP32_flash_tool.exe.

Requisiti Caricare il firmware Modalità BOOT + RESET Problemi Dove sono i file

Il programma scarica il firmware dal server e lo carica sulla scheda collegata via USB. È un file singolo: non richiede Python né installazione e si può copiare su qualsiasi PC Windows. L'elenco dei firmware disponibili è definito sul server con il Manifest Creator.

Requisiti

  • Windows 10 o 11.
  • Il driver USB-seriale della scheda: CP210x (Silicon Labs), CH340/CH9102 (WCH) o FTDI. Va installato a parte, una volta sola. Se la scheda non compare tra le porte COM, di solito manca il driver.
  • Un cavo USB che trasporti dati (alcuni cavi servono solo per la ricarica).
  • Accesso al server firmware (predefinito: http://100.42.178.156/init).

Caricare il firmware

  1. Collega la scheda al PC e avvia ST_ESP32_flash_tool.exe.
  2. Server: l'indirizzo è già compilato. All'avvio il programma legge l'elenco dei firmware disponibili; per rileggerlo, o dopo aver cambiato indirizzo, premi Carica elenco. Un indirizzo diverso da quello predefinito viene ricordato.
  3. Porta COM: il programma propone da solo la porta più probabile; se sulla porta arrivano dati dalla scheda, la seleziona automaticamente. Se hai collegato la scheda dopo l'avvio, premi Aggiorna.
  4. Chip: scegli il modello di ESP32, oppure premi Rileva chip per leggerlo dalla scheda. Sotto l'elenco compaiono il modello esatto, la memoria flash e le caratteristiche (es. ESP32-D0WD-V3 · 4MB flash · Wi-Fi, BT). Dopo il rilevamento la scheda si riavvia normalmente. L'elenco mostra solo i chip per cui sul server c'è un firmware.
  5. Scheda: scegli il firmware. Ogni voce indica tipo di scheda, prodotto e versione, ad esempio esp32dev — Modulo Pompa (MP.26.10.23.bx). Nel registro in basso compaiono la data di preparazione e i file del firmware scelto.
  6. Velocità: lascia 460800. Usa 115200 solo se il caricamento si interrompe.
  7. Modalità: scegli tra aggiornamento e installazione completa (vedi sotto).
  8. Premi Carica firmware e attendi il messaggio Firmware caricato correttamente. Alla fine la scheda si riavvia da sola.

Chip, scheda e velocità vengono ricordati e riproposti all'avvio successivo. Se hai rilevato il chip e poi scegli un firmware per un chip diverso, il programma blocca il caricamento e ti avvisa.

Aggiornamento o installazione completa?

ModalitàCosa faQuando usarla
Aggiornamento firmware Scrive solo il programma (bootloader, partizioni, applicazione). Configurazione, WiFi e file salvati sulla scheda restano. Schede già installate che devono passare a una versione nuova.
Installazione completa
(predefinita)		 Cancella tutta la memoria e scrive programma e filesystem (pagine web e file di data/). Chiede conferma prima di procedere. Schede nuove, oppure schede da riportare allo stato di fabbrica.

Attenzione: l'installazione completa cancella configurazione e credenziali WiFi della scheda.

Se la scheda non risponde: BOOT + RESET

Per essere programmato l'ESP32 deve entrare in modalità programmazione. Molte schede ci entrano da sole; altre (ad esempio quelle collegate con un adattatore che non comanda i pin EN e IO0) vanno avviate a mano. In quel caso compare l'errore Failed to connect … No serial data received.

  1. Tieni premuto il pulsante BOOT (IO0).
  2. Premi e rilascia RESET (EN).
  3. Rilascia BOOT.
  4. Premi subito Carica firmware (o Rileva chip).

Se non funziona ancora, controlla che la porta COM sia quella giusta e prova la velocità 115200.

Problemi frequenti

ProblemaCosa fare
La scheda non compare tra le porte COM Installa il driver USB-seriale (CP210x, CH340 o FTDI), prova un altro cavo, poi premi Aggiorna.
Failed to connect / No serial data received Usa la procedura BOOT + RESET e controlla la porta.
Il caricamento si interrompe a metà Imposta la velocità 115200 e riprova; evita hub USB e cavi lunghi.
Server non raggiungibile Controlla la connessione e l'indirizzo del server, poi premi Carica elenco.
Un chip o una scheda non compare negli elenchi Sul server non c'è un firmware disponibile per quella combinazione: il registro in basso indica le cartelle non disponibili e il motivo. Va sistemato con il Manifest Creator.
Sulla COMx è collegato un …, ma il firmware scelto è per … Il firmware scelto è per un altro chip: scegli la scheda giusta per il chip rilevato.
Wrong --chip argument? La scheda collegata ha un chip diverso da quello scelto: premi Rileva chip e scegli di nuovo la scheda.
checksum non valido, download corrotto Il file scaricato non corrisponde al manifest.json del server: riprova; se si ripete, la cartella sul server va ripubblicata.

Dove sono i file

CosaPercorso
Firmware scaricati (cache) %LOCALAPPDATA%\ST_ESP32_flash_tool\cache\, una sottocartella per ogni cartella del server
Impostazioni (indirizzo server, chip, scheda, velocità) %APPDATA%\ST_ESP32_flash_tool\config.json

Prima di ogni caricamento i file in cache vengono controllati con il checksum del manifest.json: se sul server sono cambiati vengono riscaricati. La cartella cache si può cancellare in qualsiasi momento.
