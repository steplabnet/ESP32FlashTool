ST ESP32 Flash Tool

Come caricare il firmware sulle schede ESP32 con ST_ESP32_flash_tool.exe.

Requisiti La finestra Caricare il firmware Modalità File aggiuntivi Log BOOT + RESET Problemi Dove sono i file

Il programma scarica il firmware dal server e lo carica sulla scheda collegata via USB. È un file singolo: non richiede Python né installazione e si può copiare su qualsiasi PC Windows. All'avvio impiega qualche secondo ad aprirsi. L'elenco dei firmware disponibili è definito sul server con il Manifest Creator.

Requisiti

  • Windows 10 o 11.
  • Il driver USB-seriale della scheda: CP210x (Silicon Labs), CH340/CH9102 (WCH) o FTDI. Va installato a parte, una volta sola. Se la scheda non compare tra le porte COM, di solito manca il driver.
  • Un cavo USB che trasporti dati (alcuni cavi servono solo per la ricarica).
  • Accesso al server firmware (predefinito: http://100.42.178.156/init).

La finestra

In alto ci sono tre schede: Dispositivo, Opzioni e Log. In basso, sempre visibili, ci sono il pulsante Carica firmware, la barra di avanzamento e la riga di stato, che dice cosa sta facendo il programma.

SchedaContenuto
Dispositivo Server, porta COM, chip, scheda (il firmware da caricare) e velocità.
Opzioni Modalità di caricamento (aggiornamento o installazione completa) e file aggiuntivi da inserire nel filesystem.
Log Il registro di tutto quello che fa il programma: firmware disponibili, rilevamenti, avanzamento ed eventuali errori.

Caricare il firmware

  1. Collega la scheda al PC e avvia ST_ESP32_flash_tool.exe. Si apre sulla scheda Dispositivo.
  2. Server: l'indirizzo è già compilato. All'avvio il programma legge l'elenco dei firmware disponibili; per rileggerlo, o dopo aver cambiato indirizzo, premi Carica elenco (o Invio nel campo). Un indirizzo diverso da quello predefinito viene ricordato.
  3. Porta COM: il programma propone da solo la porta più probabile; se sulla porta arrivano dati dalla scheda, la seleziona automaticamente (la riga di stato mostra Scheda rilevata su COMx). Se hai collegato la scheda dopo l'avvio, premi Aggiorna.
  4. Chip: scegli il modello di ESP32, oppure premi Rileva chip per leggerlo dalla scheda. Sotto l'elenco compaiono il modello esatto, la memoria flash e le caratteristiche (es. ESP32-D0WD-V3 · 4MB flash · Wi-Fi, BT). Dopo il rilevamento la scheda si riavvia normalmente. L'elenco mostra solo i chip per cui sul server c'è un firmware.
  5. Scheda: scegli il firmware. Ogni voce indica tipo di scheda, prodotto e versione, ad esempio esp32dev — Modulo Pompa (MP.26.10.23.bx). Nella scheda Log compaiono la data di preparazione e i file del firmware scelto.
  6. Velocità: lascia 460800. Usa 115200 solo se il caricamento si interrompe.
  7. Opzioni: controlla nella scheda Opzioni la modalità (vedi sotto). La predefinita è l'installazione completa.
  8. Premi Carica firmware. Il programma passa da solo alla scheda Log, dove segui l'avanzamento. Attendi il messaggio Firmware caricato correttamente: alla fine la scheda si riavvia da sola.

Chip, scheda e velocità vengono ricordati e riproposti all'avvio successivo. Se hai rilevato il chip e poi scegli un firmware per un chip diverso, il programma blocca il caricamento e ti avvisa.

Aggiornamento o installazione completa?

Si sceglie nel riquadro Modalità della scheda Opzioni.

ModalitàCosa faQuando usarla
Aggiornamento firmware Scrive solo il programma (bootloader, partizioni, applicazione). Configurazione, WiFi e file salvati sulla scheda restano. Schede già installate che devono passare a una versione nuova.
Installazione completa
(predefinita)		 Cancella tutta la memoria e scrive programma e filesystem (pagine web e file di data/). Chiede conferma prima di procedere. Schede nuove, oppure schede da riportare allo stato di fabbrica.

Attenzione: l'installazione completa cancella configurazione e credenziali WiFi della scheda.

Aggiungere file al filesystem

Con l'installazione completa si possono caricare sulla scheda, insieme al firmware, file presi dal PC: ad esempio un file di configurazione già pronto o pagine web personalizzate.

  1. Nella scheda Opzioni accendi l'interruttore a destra di File aggiuntivi nel filesystem: compaiono l'elenco e i pulsanti. Con l'interruttore spento i file non vengono caricati. La sua posizione viene ricordata.
  2. Premi Aggiungi file… per scegliere uno o più file: vanno nella radice del filesystem (es. config.json → /config.json).
  3. Oppure premi Aggiungi cartella…: viene copiato il contenuto della cartella con le sue sottocartelle, come la cartella data/ dei progetti (es. miacartella/img/logo.png → /img/logo.png).
  4. Con Rimuovi togli dall'elenco le voci selezionate.
  5. Premi Carica firmware: la conferma indica quanti file verranno aggiunti.

I pulsanti funzionano solo con la modalità Installazione completa: con l'aggiornamento il filesystem della scheda non viene toccato.

Prima del caricamento il programma estrae il filesystem del firmware scaricato, aggiunge i file e lo ricostruisce. Un file con lo stesso percorso di uno del firmware lo sostituisce. Nel log compare l'elenco dei file, ciascuno con aggiunto o sostituito. Il firmware sul server e la copia in cache non vengono modificati.

LimiteLittleFS (Centrale)SPIFFS (Modulo Pompa)
Lunghezza dei nomi32 caratteri per ogni nome di file o cartella 31 caratteri per il percorso completo, / iniziale compreso
SpazioI file del firmware e quelli aggiunti devono stare insieme nella partizione filesystem (circa 1,4 MB)

Se un nome è troppo lungo, il programma lo segnala prima di iniziare; se i file non ci stanno, il caricamento si ferma prima di scrivere sulla scheda.

L'elenco dei file aggiuntivi non viene salvato: alla chiusura del programma si svuota, così non si caricano per errore file pensati per un'altra scheda.

Il log

La scheda Log raccoglie tutti i messaggi: l'elenco dei firmware letti dal server (con le cartelle non disponibili e il motivo), i file del firmware scelto, i messaggi di esptool durante il caricamento e gli errori. Se qualcosa non va, è il primo posto da guardare; il testo si può selezionare e copiare con Ctrl+C per inviarlo all'assistenza.

Se la scheda non risponde: BOOT + RESET

Per essere programmato l'ESP32 deve entrare in modalità programmazione. Molte schede ci entrano da sole; altre (ad esempio quelle collegate con un adattatore che non comanda i pin EN e IO0) vanno avviate a mano. In quel caso compare l'errore Failed to connect … No serial data received.

  1. Tieni premuto il pulsante BOOT (IO0).
  2. Premi e rilascia RESET (EN).
  3. Rilascia BOOT.
  4. Premi subito Carica firmware (o Rileva chip).

Se non funziona ancora, controlla che la porta COM sia quella giusta e prova la velocità 115200.

Problemi frequenti

ProblemaCosa fare
La scheda non compare tra le porte COM Installa il driver USB-seriale (CP210x, CH340 o FTDI), prova un altro cavo, poi premi Aggiorna.
Failed to connect / No serial data received Usa la procedura BOOT + RESET e controlla la porta.
Il caricamento si interrompe a metà Imposta la velocità 115200 e riprova; evita hub USB e cavi lunghi.
Server non raggiungibile Controlla la connessione e l'indirizzo del server, poi premi Carica elenco.
Un chip o una scheda non compare negli elenchi Sul server non c'è un firmware disponibile per quella combinazione: la scheda Log indica le cartelle non disponibili e il motivo. Va sistemato con il Manifest Creator.
Sulla COMx è collegato un …, ma il firmware scelto è per … Il firmware scelto è per un altro chip: scegli la scheda giusta per il chip rilevato.
Wrong --chip argument? La scheda collegata ha un chip diverso da quello scelto: premi Rileva chip e scegli di nuovo la scheda.
checksum non valido, download corrotto Il file scaricato non corrisponde al manifest.json del server: riprova; se si ripete, la cartella sul server va ripubblicata.
I pulsanti dei file aggiuntivi sono grigi Sono attivi solo con l'Installazione completa e mentre non è in corso un caricamento.

Dove sono i file

CosaPercorso
Firmware scaricati (cache) Cartella cache\ accanto a ST_ESP32_flash_tool.exe, con una sottocartella per ogni cartella del server. Se lì non si può scrivere (ad esempio con il programma in C:\Program Files), in %LOCALAPPDATA%\ST_ESP32_flash_tool\cache\.
Impostazioni (indirizzo server, chip, scheda, velocità, interruttore dei file aggiuntivi) config.json accanto a ST_ESP32_flash_tool.exe. Se lì non si può scrivere, in %APPDATA%\ST_ESP32_flash_tool\config.json.

Prima di ogni caricamento i file in cache vengono controllati con il checksum del manifest.json: se sul server sono cambiati vengono riscaricati. La cartella cache si può cancellare in qualsiasi momento.
